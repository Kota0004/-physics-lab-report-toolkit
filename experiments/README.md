# 物理学実験 データアーカイブ

日本大学理工学部 物理学科 物理学実験(金曜班・二川航大 4143)の
**測定データ・配布資料・図・提出レポート**を実験ごとにまとめた保管用フォルダ。
今後のレポート作成時の参照元。レポート生成の仕組みは同リポジトリ直下の
`lib/` `scripts/` `examples/` を参照。

## ⚠️ 非公開必須

このフォルダには次が含まれるため、**リポジトリは必ず Private のままにすること**。

- 手書き表紙・予習スキャン(**氏名・学生番号・担当教員名**などの個人情報)
- 大学の**配布資料**および**教科書スキャン**(出版社・大学の著作物)

教科書スキャンは容量削減のため低解像度に再圧縮した参考版のみ収録
(マイケルソン 106 MB → 2.6 MB、プランク 85 MB → 2.1 MB)。

## 構成

```
00_共通資料/          レポートの書き方(全実験共通の手引き)
01_熱の伝播/           report/(提出PDF)※生データは未保管
02_線スペクトルとリュードベリ定数/  report/(提出PDF)※生データは未保管
03_放射性物質の崩壊/    report/(提出PDF)※生データは未保管
04_マイケルソン干渉計/
    data/       week1_wavelength_refractive_index(TEK CSV/xlsx), week2_coherence(619.xlsx)
    materials/  追加資料, 手書き表紙, 教科書(低解像度)
    photos/     Igor フィッティング画面, 実験ノート
    figures/    レポート掲載図(fig1〜5)
    report/     提出レポート(docx / pdf)
05_プランク定数/
    data/       プランク定数.xlsx(較正・I–V・読み取り・最小二乗の全測定値)
    materials/  課題等(配布資料), グラフ1(手描き片対数), 手書き表紙, 教科書(低解像度)
    figures/    レポート掲載図(fig1〜4, Excelグラフ書き出し)
    report/     提出レポート(docx / pdf)
06_核磁気共鳴/
    data/       nmr_measurements.csv(発振周波数 8.0〜11.0 MHz の 7 点の共鳴磁場)
    materials/  表紙予習・課題シート(手書きスキャン・磁場記入済), 教科書(低解像度)
    figures/    レポート掲載図(fig1, matplotlib 作成)
    report/     提出レポート(docx / pdf)
```

各実験フォルダは番号順(実験の実施順)。`report/` の PDF が提出版。

## 各実験の概要

| # | 実験 | 主な結果 |
|---|---|---|
| 1 | 熱の伝播 | (提出レポートのみ) |
| 2 | 線スペクトルとリュードベリ定数 | (提出レポートのみ) |
| 3 | 放射性物質の崩壊 | (提出レポートのみ) |
| 4 | マイケルソン干渉計 | λ = 523 ± 3 nm、n(空気) = 1.000238、L_c,eff = 0.21 mm |
| 5 | プランク定数 | h = (7.76 ± 0.19)×10⁻³⁴ J·s、eφ = 1.89 ± 0.07 eV |
| 6 | 核磁気共鳴 | df/dB = 4.2003×10⁷ Hz/T、γn = 2.6391×10⁸ s⁻¹·T⁻¹、gn = 5.5103(理想値 −1.35 %) |

## メモ

- 実験 1〜3 は提出 PDF のみが手元にあり、生データ(Excel 等)は保管していない。
- マイケルソンとプランクの図は Excel 埋め込みグラフを PNG 書き出ししたもの
  (作成手順は report-toolkit の `scripts/export-excel-charts.ps1`)。
- 核磁気共鳴の図は matplotlib で作成(生成スクリプトとレポート生成一式は
  `examples/nmr/`。Linux + LibreOffice でのビルド見本にもなっている)。
